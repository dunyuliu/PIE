# Citing

PIE is released under the GNU General Public License v3.0. If you use it in
published work, please cite:

Dunnigan, A. H., Liu, D., Steinbrügge, G. B., Rivoldini, A., Dumberry, M.,
Cao, H., & Soderlund, K. M. (2026). Interior models of Mercury and
conditions for iron snow formation in a Fe-S-Si core. *Journal of
Geophysical Research: Planets*, 131(4), e2025JE009368.
https://doi.org/10.1029/2025JE009368

PIE's present-day model supersedes an earlier sulfur-only predecessor:

Steinbrügge, G., et al. (2020). https://doi.org/10.1029/2020GL089895

## Archived code and data

Code and data archived on Zenodo for the Dunnigan et al. 2026 paper (PIE
v1.0.5):

* Code: https://doi.org/10.5281/zenodo.16929504
* Simulation dataset and plotting scripts: https://doi.org/10.5281/zenodo.16459292
